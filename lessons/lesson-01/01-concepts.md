# Lesson 1 — 문법과 핵심 개념

## 1. 핵심 문법

### print() 함수
- `print()`는 괄호 안의 값을 화면에 출력하는 함수이다.
- 문자열은 작은따옴표(`'`) 또는 큰따옴표(`"`)로 감싼다.
- 숫자는 따옴표 없이 작성할 수 있다.

```python
print("안녕하세요!")
print(25 + 17)
```

## 2. 문자열과 숫자의 차이

```python
print("25 + 17")  # 문자 그대로 출력
print(25 + 17)    # 계산 결과 출력
```

## 3. 코드 구조와 실행 흐름
- Python은 기본적으로 코드를 위에서 아래로 실행한다.
- `print()`를 여러 번 사용하면 각 결과가 순서대로 출력된다.
- 따옴표가 없으면 Python은 해당 글자를 문자열이 아니라 이름으로 해석할 수 있다.
