# Lesson 1 — 출력과 문자열

## 1. 핵심 문법

### print() 함수
- `print()`는 괄호 안의 값을 화면에 출력하는 함수이다.
- 문자열은 작은따옴표(`'`) 또는 큰따옴표(`"`)로 감싼다.
- 숫자는 따옴표 없이 작성할 수 있다.

```python
print("안녕하세요!")
print(25 + 17)
```

## 2. 문자열과 숫자의 차이

```python
print("25 + 17")  # 문자 그대로 출력
print(25 + 17)    # 계산 결과 출력
```

## 3. 코드 구조와 실행 흐름
- Python은 기본적으로 코드를 위에서 아래로 실행한다.
- `print()`를 여러 번 사용하면 각 결과가 순서대로 출력된다.
- 따옴표가 없으면 Python은 해당 글자를 문자열이 아니라 이름으로 해석할 수 있다.

## 4. 복습 문제와 풀이

### 기본 문제 — 개발자 소개 출력

```python
print("안녕하세요!")
print("저는 백엔드 개발자를 꿈꾸고 있습니다.")
print("파이썬 공부 1일차")
print(f"25 + 17 = {25 + 17}")
print("오늘도 화이팅!")
```

**구조적 개념**
- 코드는 위에서 아래로 실행된다.
- f-string의 `{}` 안에는 계산식을 넣을 수 있다.
- 계산식의 결과가 문자열에 삽입된 후 출력된다.

### 응용 문제 — 계산 출력 오류 수정

```python
print("=== 계산 기록 ===")
print(f"10 + 5 = {10 + 5}")
print(f"10 * 5 = {10 * 5}")
print("계산 완료!")
```

**구조적 개념**
- 일반 문자열에서는 중괄호 안의 계산식을 실행하지 않는다.
- f-string에서는 중괄호 안의 표현식을 계산한 뒤 결과를 삽입한다.
- print()는 쉼표로 여러 값을 구분하여 출력할 수도 있다.
