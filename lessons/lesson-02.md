# Lesson 2 — 변수와 자료형

## 1. 핵심 문법

### 변수란?

변수는 데이터를 저장하고 이름을 붙이는 방법이다.

```python
name = "승엽"
age = 25

print(name)
print(age)
```

- `=`는 오른쪽 값을 왼쪽 변수에 대입한다.
- 변수 이름을 이용해 저장된 값을 다시 사용할 수 있다.
- 변수에 새로운 값을 대입하면 기존 값이 바뀐다.

### 기본 자료형

```python
name = "승엽"    # str: 문자열
age = 25        # int: 정수
height = 175.5  # float: 실수
```

- `str`: 문자나 문자열
- `int`: 정수
- `float`: 소수점이 있는 숫자
- `type()`을 사용하면 자료형을 확인할 수 있다.

### f-string

문자열 안에 변수나 계산 결과를 삽입할 수 있다.

```python
name = "승엽"
age = 25

print(f"이름: {name}")
print(f"나이: {age}세")
print(f"내년 나이: {age + 1}세")
```

### input() 함수

사용자로부터 입력값을 받는다.

```python
name = input("이름을 입력하세요: ")
print(f"안녕하세요, {name}님!")
```

`input()`으로 받은 값은 기본적으로 문자열이다.

## 2. 코드 구조와 실행 흐름

### 변수의 데이터 흐름

1. 오른쪽 값을 계산하거나 준비한다.
2. 계산된 값을 왼쪽 변수에 저장한다.
3. 이후 코드에서 변수 이름으로 값을 사용한다.

```python
score = 80
score = score + 10

print(score)  # 90
```

두 번째 줄은 기존 `score` 값에 10을 더한 뒤
결과를 다시 `score`에 저장한다.

### 변수와 문자열의 차이

```python
name = "승엽"

print(name)    # 승엽
print("name")  # name
```

따옴표가 있으면 문자열로 취급한다.
따옴표가 없으면 변수 이름으로 해석한다.

## 3. 기억할 핵심

- 변수는 값을 저장하고 재사용하기 위한 이름이다.
- `=`는 수학의 같다는 뜻이 아니라 대입 연산자다.
- 문자열과 숫자는 서로 다른 자료형이다.
- f-string의 중괄호 안에는 변수나 계산식을 넣을 수 있다.
- `input()`은 문자열을 반환한다.
